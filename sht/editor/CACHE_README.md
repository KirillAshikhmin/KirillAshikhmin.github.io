# Настройка кэширования

## Как это работает

Все ресурсы (CSS, JS файлы) имеют версию в URL параметре `?v=...`. Это позволяет:

1. **Долгое кэширование**: Браузер кэширует файлы на длительный срок (до 1 года)
2. **Автоматическое обновление**: При изменении версии браузер загружает новые файлы

## Обновление версии

### Автоматически (рекомендуется)

Используйте скрипт `update-version.sh`:

```bash
# Автоматическая версия (на основе даты)
./update-version.sh

# Или укажите версию вручную
./update-version.sh 1.0.1-20250126
```

Скрипт автоматически обновит версию во всех ресурсах в `index.html` и в `version.json`.

### Вручную

1. Откройте `index.html`
2. Найдите все вхождения `?v=1.0.0-20250125` (или текущей версии)
3. Замените на новую версию, например `?v=1.0.1-20250126`
4. Обновите `version.json` с новой версией

## Формат версии

Рекомендуемый формат: `v=X.Y.Z-YYYYMMDD`

- `X.Y.Z` - семантическая версия (major.minor.patch)
- `YYYYMMDD` - дата сборки

Примеры:
- `v=1.0.0-20250125`
- `v=1.0.1-20250126`
- `v=2.0.0-20250201`

## Что кэшируется

- ✅ Все CSS файлы (vendor/*.css, style.css)
- ✅ Все JS файлы (vendor/*.js, scripts/*.js)
- ✅ HTML файл (index.html) - кэшируется с проверкой обновлений

## Meta-теги кэширования

В HTML добавлены meta-теги для управления кэшем:
- `Cache-Control: public, max-age=31536000, immutable` - для статических ресурсов
- `Expires: 31536000` - срок действия кэша (1 год)

## Примечания

- При изменении любого файла (CSS/JS) обязательно обновите версию
- Версия должна быть одинаковой для всех ресурсов в одном релизе
- Браузеры автоматически инвалидируют кэш при изменении URL (включая query параметры)
